Separation logic (SL) is a general-purpose logic for reasoning about independence, the principle that underlies all design principles. Rather than being tightly tied to any specific language, separation logic focuses on the way the state can be divided and reasoned about independently. This allows us to use a unified formalism for reasoning across the spectrum from hardware to hypervisors, processes to systems. As a part of this unified formalism, BlueRock aims to expand our verification tools to other languages in the future with separation logic as the foundational logical component. If you've interested in reasoning about a particular programming language, let us know!
