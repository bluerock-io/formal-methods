FM Website
===========

This website should be focused on potential customers and collaborators. It should contain content that is consumable to lightly technical people (little background in formal verification), but it should also contain justifications for statements that are made by citing technical reports.

Build Instructions
-------------------

This site is built using [11ty](https://www.11ty.dev/). You can run a local server with

```sh
npx @11ty/eleventy --serve --watch
```
